# AsiaTechnoStroy

Сайт компании по обслуживанию инженерных систем в Ташкенте. Производственная версия публикуется из ветки `main` через Cloudflare Workers.

## Устройство проекта

- `public/` — страницы, стили, изображения и браузерный калькулятор.
- `public/pricing.js` — единые правила расчёта для страницы и сервера.
- `src/worker.js` — защищённая обработка заявок `/send`, проверка расчёта и уведомление в Telegram.
- `test/` — проверки калькулятора и обработчика заявок.
- `wrangler.jsonc` — конфигурация Cloudflare, статических файлов и ограничения частоты заявок.

## Локальный запуск

Требуется Node.js 24.

```bash
corepack enable
pnpm install --frozen-lockfile
cp .dev.vars.example .dev.vars
pnpm dev
```

Значения `TOKEN` и `CHAT_ID` в `.dev.vars` нужны только для тестовой отправки уведомлений. Файл `.dev.vars` не попадает в Git.

## Проверки

```bash
pnpm run check
pnpm exec wrangler deploy --dry-run
```

## Публикация

Cloudflare Workers Builds использует `wrangler.jsonc` и закреплённую в `package.json` версию Wrangler. Для уведомлений формы в настройках Worker должны быть добавлены runtime-секреты `TOKEN` и `CHAT_ID`. Секреты нельзя хранить в репозитории или в переменных сборки.

Основная ветка разворачивается в production, остальные ветки создают preview-версии. Клиент не передаёт готовую стоимость: Worker повторно рассчитывает её по тем же правилам перед созданием ответа.
