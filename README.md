# AsiaTechnoStroy

Многоязычный B2B-сайт компании по эксплуатации и техническому аудиту инженерных систем в Ташкенте. Русский язык открыт по умолчанию, узбекская и английская версии имеют собственные индексируемые адреса. Производственная версия публикуется из ветки `main` через Cloudflare Workers.

## Устройство проекта

- `site/content.mjs` — единый источник текстов, навигации, адресов страниц и словарей RU/UZ/EN.
- `site/render.mjs` — шаблоны страниц и структурированных данных для поисковых систем.
- `scripts/build-site.mjs` — генератор 18 статических страниц, sitemap, robots, редиректов и защитных заголовков.
- `public/` — готовые страницы, стили, изображения и браузерный калькулятор. HTML и `i18n.js` здесь генерируются и не редактируются вручную.
- `public/pricing.js` — единые правила расчёта для страницы и сервера.
- `src/worker.js` — защищённая обработка заявок `/send`, проверка расчёта и уведомление в Telegram.
- `test/` — проверки страниц, SEO-разметки, калькулятора и обработчика заявок.
- `wrangler.jsonc` — конфигурация Cloudflare, статических файлов и ограничения частоты заявок.

## Страницы

Для каждого языка генерируются главная, «О компании», технический аудит, комплексная эксплуатация, контакты и информация об обработке данных. Переключатель языка всегда ведёт на эквивалент текущей страницы. Карточки инженерных направлений пока остаются интерактивными визуальными элементами: их можно последовательно превратить в отдельные разделы без переделки общей структуры.

## Калькулятор

Калькулятор принимает площадь от 500 до 150 000 м². Стоимость растёт накопительно: часть площади в каждом следующем диапазоне считается по своей пониженной ставке, поэтому пересечение границы не удешевляет уже рассчитанные метры. Технический аудит имеет отдельную разовую шкалу и на контрольных площадях остаётся дешевле месячного обслуживания даже одной базовой системы. Все суммы являются предварительным ориентиром до согласования состава оборудования и границ работ.

## Локальный запуск

Требуется Node.js 24.

```bash
corepack enable
pnpm install --frozen-lockfile
cp .dev.vars.example .dev.vars
pnpm dev
```

Значения `TOKEN` и `CHAT_ID` в `.dev.vars` нужны только для тестовой отправки уведомлений. Файл `.dev.vars` не попадает в Git.

## Проверки

```bash
pnpm run build
pnpm run check
pnpm exec wrangler deploy --dry-run
```

После изменения `site/content.mjs` или `site/render.mjs` необходимо выполнить `pnpm run build` и сохранить обновлённые файлы из `public/`. Команда `pnpm run check` отдельно подтверждает, что сгенерированная версия не устарела.

## Публикация

Cloudflare Workers Builds использует `wrangler.jsonc` и закреплённую в `package.json` версию Wrangler. Для уведомлений формы в настройках Worker должны быть добавлены runtime-секреты `TOKEN` и `CHAT_ID`. Секреты нельзя хранить в репозитории или в переменных сборки.

Основная ветка разворачивается в production, остальные ветки создают preview-версии. Клиент не передаёт готовую стоимость: Worker повторно рассчитывает её по тем же правилам перед созданием ответа. Стоимости в калькуляторе являются предварительным ориентиром; итоговая цена определяется после согласования границ аудита или обслуживания.

## Запуск индексации

После публикации новой версии:

1. В Cloudflare привязать `www.asiatechnostroy.uz` к этому Worker как второй Custom Domain — одной DNS-записи недостаточно. После привязки Worker выполняет постоянное перенаправление с HTTP и `www` на `https://asiatechnostroy.uz` с сохранением пути и параметров.
2. Подтвердить домен через DNS в Google Search Console и передать `https://asiatechnostroy.uz/sitemap.xml`.
3. Добавить основной HTTPS-адрес в Яндекс Вебмастер, подтвердить права и передать тот же sitemap.
4. При необходимости импортировать подтверждённый сайт в Bing Webmaster Tools. IndexNow уже подключён; дополнительно можно включить Cloudflare Crawler Hints.
5. Создать или подтвердить только достоверные карточки компании в Google Business Profile и Яндекс Бизнес: телефон, сайт, реальная зона обслуживания и фотографии.

`robots.txt`, sitemap, канонические адреса, языковые связи и структурированные данные генерируются автоматически. Они помогают поисковым роботам обнаружить и правильно связать страницы, но сама регистрация не гарантирует позицию или срок появления в выдаче.

## IndexNow

Публичный файл `public/indexnow-key.txt` подтверждает право сайта отправлять уведомления IndexNow. После публикации новых или изменённых страниц их можно передать Bing, Яндексу и другим участникам протокола:

```bash
pnpm run indexnow
```

Без аргументов отправляются 18 канонических адресов из sitemap — это предназначено для крупных релизов, в которых перегенерированы все страницы. Для точечного обновления передаются только изменённые адреса из sitemap:

```bash
pnpm run indexnow -- /o-kompanii/ /uz/kompaniya-haqida/ /en/about/
```
